## Install

<CodeGroup>
```bash pip
pip install radical.adr # not released yet, please install from source
```

```bash source
git clone https://github.com/radical-cybertools/radical.adr
cd radical.adr && pip install -e .
```
</CodeGroup>

## What you get

ADR sits on top of [AsyncFlow](https://github.com/radical-cybertools/radical.asyncflow), which
provides the `WorkflowEngine` and execution backends. A minimal local setup needs nothing beyond
the Python standard library's executors:

```python
from concurrent.futures import ThreadPoolExecutor   # or ProcessPoolExecutor
from radical.asyncflow import LocalExecutionBackend, WorkflowEngine

backend = await LocalExecutionBackend(ThreadPoolExecutor(max_workers=8))
engine  = await WorkflowEngine.create(backend)
```

<Note>
**Thread vs process executor.** With `ProcessPoolExecutor`, any function dispatched via
`engine.function_task(...)` must be a **module-level, importable (picklable)** async function.
With `ThreadPoolExecutor` or local execution, any async function works. See
[AsyncFlow integration](/integrations/asyncflow).
</Note>

## AsyncFlow feature branch

ADR relies on block-cancellation support in AsyncFlow (the `feature/enable_block_cancellation`
branch): `future.state` polling for `PENDING → RUNNING` promotion, block-cancellation propagation
to spawned tasks, and an idempotent task-cancellation path. If you cancel operators or tasks at
runtime, ensure your AsyncFlow build includes it. See
[AsyncFlow integration](/integrations/asyncflow#feature-branch-dependency).
