## `Goal`

```python
Goal(name, metric, threshold, direction="minimize", inclusive=False)
```

A dataclass. Satisfied when `obs[metric]` crosses `threshold`.

| Field | Type | Default | Meaning |
|---|---|---|---|
| `name` | `str` | — | Identity. A runtime goal with the same name upserts in place. |
| `metric` | `str` | — | Key looked up in the observation dict. |
| `threshold` | `float` | — | Boundary value. |
| `direction` | `str` | `"minimize"` | `"minimize"` → satisfied when `value < threshold`; `"maximize"` → `value > threshold`. |
| `inclusive` | `bool` | `False` | `True` flips to `<=` / `>=`. |
| `for_cycles` | `int` | `1` | Must hold this many consecutive cycles to count as met (debounce). |

### `satisfied(obs, snapshot) -> bool`

Metric lookup order:

1. `obs[metric]` — primary (what `@observe` returned).
2. `snapshot.objectives[metric]` — fallback (operator state).

If the metric is found in neither, returns `False` and emits a one-time `UserWarning`.
`snapshot.runtime` is **not** consulted — surface resource metrics through `@observe`.

```python
# minimize: satisfied when value < 0.005  (or <= with inclusive=True)
Goal(name="converged", metric="radius", threshold=0.005, direction="minimize")

# maximize, inclusive: fires at exactly 5 hits
Goal(name="hits", metric="n_hits", threshold=5, direction="maximize", inclusive=True)
```

## `AnyGoal` / `AllGoal`

```python
AnyGoal(goals: list, name: str | None = None)   # satisfied when ANY member is (OR)
AllGoal(goals: list, name: str | None = None)   # satisfied when ALL members are (explicit AND)
```

Composite goals with the same `.satisfied(obs, snapshot)` contract as `Goal`; members may be plain
`Goal`s or nested groups. Imported from `radical.adr`. A bare list returned from `@goals` is implicit
AND — `AllGoal` only differs by being composable inside an `AnyGoal`.

## Static vs runtime goals

- **Static** — returned by an operator's `@goals` method.
- **Runtime** — proposed by a policy via `Decision(goals=[...])`, removed via
  `Decision(remove_goals=["name"])`.

Both are evaluated together every cycle; the operator stops when **all** are satisfied. See
[Goals & convergence](/guides/goals-and-convergence).

A runtime goal whose `name` or `metric` collides with a **static** goal is **rejected** (dropped +
logged) — a policy can add stricter goals on *other* metrics but can never shadow or relax the
authoritative objective. A hard resource/compute cap is not a goal at all — use
[`Budget`](/reference/api-boundary).
