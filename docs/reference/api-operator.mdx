## `Operator`

```python
Operator(
    engine,
    operator_id=None,
    *,
    policy=None,
    parent=None,
    inbox_maxsize=0,
    observer=None,
    max_cycles=None,
    max_runtime=None,
    budget=None,
)
```

Subclass to define a campaign. Annotated class attributes with defaults become persistent
objectives (proxied to `state.objectives`).

| Parameter | Type | Meaning |
|---|---|---|
| `engine` | `WorkflowEngine` | AsyncFlow engine (required). |
| `operator_id` | `str \| None` | Stable id; defaults to the class name. |
| `policy` | `Policy \| None` | Decision policy; may also be set via `op.policy = ...`. |
| `parent` | `Operator \| None` | Set automatically for child operators. |
| `inbox_maxsize` | `int` | Max size of the operator's inbox (0 = unbounded). |
| `observer` | `ObserverBase \| None` | Lifecycle observer. |
| `max_cycles` | `int \| None` | Stop condition — force stop after N cycles. |
| `max_runtime` | `float \| None` | Stop condition — force stop after N wall-clock seconds. |
| `budget` | `list[Budget] \| None` | Stop condition(s) on observed metrics, evaluated independently of goal state. See [api-boundary](/reference/api-boundary). |

### Class attributes

Set on the subclass (not passed to `__init__`):

| Attribute | Type | Meaning |
|---|---|---|
| `decide_when` | `str \| None` | Cadence gate. `None` (default) consults the policy every cycle; `"idle"` only when `inflight == 0`; `"new_result"` only when a task result landed this cycle. On skipped cycles `@observe`, goals, and budgets still run. |
| *(any)* `= Tunable(...)` | `Tunable` | Declares a bounded, agent-tunable parameter — the adaptation boundary. See [api-boundary](/reference/api-boundary). |

### Methods

| Method | Returns | Description |
|---|---|---|
| `run()` | async generator of `Snapshot` | Drives the cycle; yields one `Snapshot` per cycle. |
| `run_to_completion()` | `Snapshot` | Consumes `run()`, returns the final snapshot. |
| `start(*dep_futures)` | `Future` | Wraps `run_to_completion()` as an `engine.block`. Internal — used by `SPAWN_OPERATOR`. |
| `shutdown()` | — | Sets the stop event, posts `STOP` to the inbox. |
| `get_actions(format=None)` | `ActionSet` \| schema list | The operator's `ActionSet`; with `"openai"`/`"anthropic"`/`"langgraph"`, renders tool schemas. |
| `add_child(name, OperatorCls, *, policy=…, **config)` | — | Declare a child operator. `policy=` accepts a `Policy` instance or a class/factory called with the child. |
| `child(name)` | `ChildHandle` | Read-only handle to a declared child. |
| `save_checkpoint(path)` | — | Serialize steering state (cycle, objectives, goals, task_context, child metadata) to JSON. |
| `load_checkpoint(path)` | — | Restore steering state onto a freshly constructed operator, then `run()` to resume. |
| `trend(metric, direction, *, eps=1e-9)` | `str` | `"improving"`/`"flat"`/`"regressing"` over the metric's distinct value history. `direction` (`"maximize"`/`"minimize"`) is required. |
| `stalled(metric, direction, n, *, eps=1e-9)` | `bool` | Whether the metric failed to improve across its last `n` distinct values. |

### Attributes

| Attribute | Description |
|---|---|
| `operator_id` | The operator's id. |
| `engine` | The AsyncFlow engine. |
| `policy` | The attached `Policy`. |
| `cycle_history` | `list[Snapshot]` of previous completed cycles (read in `@observe`). |
| `inflight` | `int` — count of tasks with status `PENDING` or `RUNNING`. Surface it in `@observe` (`"inflight": self.inflight`) to self-throttle, or target it with a `Goal`. |
| `tunables` | `dict` — current `{name: value}` of the declared `Tunable` boundary. |
| `rejections` | `list` — boundary rejections pending until the next decision consumes them. |

## Decorators

| Decorator | On | Contract |
|---|---|---|
| `@observe` | Operator method | **Mandatory.** `(self, snapshot) -> dict`. Single assembly point for metrics. |
| `@goals` | Operator method | Optional. `(self) -> Goal \| list[Goal]`. Static convergence criteria. |
| `@act` | Operator async method | A capability. Return `Future` (async), plain value (local), or `None` (no-op). |

## `ChildHandle`

Read-only view returned by `op.child(name)`. See
[Hierarchical operators](/guides/hierarchical-operators).

| Accessor | Returns | Meaning |
|---|---|---|
| `.status` | `str` | `NOT_STARTED` / `PENDING` / `RUNNING` / `DONE` / `FAILED` / `CANCELED`. |
| `.started` | `bool` | `status != "NOT_STARTED"` — `True` once ever launched. |
| `.done` | `bool` | Terminal success. |
| `.failed` | `bool` | Terminal failure. |
| `.get(metric, default=None)` | `Any` | Soft read of a reported objective. |
| `.<metric>` | `Any` | Reported objective by name; raises `AttributeError` if never reported. |
